# wylon

**A reliable, easy-to-use Token Factory built on Chinese infrastructure.**

Chat models behind one API key, compatible with the major inference API protocols. The same key also calls image and video generation models.

This is the official GitHub organization of wylon, home to our open-source projects, SDKs, and ecosystem integrations.

## Why wylon

| | |
|---|---|
| **One key for the harnesses you use** | Codex, OpenCode, OpenClaw, Hermes and other agents connect with a few lines of config |
| **Image and video generation too** | The same API key calls image and video generation models |
| **Token plans** | From ¥9.9 a month, billed monthly, with no 5-hour or weekly caps |
| **Enterprise** | Dedicated plans, model allowlisting, higher rate limits, and early access to GPU Supernode |

## Open source

- **SDKs and examples** for building on the wylon API
- **Developer tools** for inference workflows
- **Ecosystem plugins**, such as ComfyUI custom nodes

Repositories will appear here as they're published.
