# wylon

**Production AI inference on wylon.** An LLM inference cloud for developers and enterprises, built on domestic GPUs.

This is the official GitHub organization of wylon, home to our open-source projects, SDKs, and ecosystem integrations.

## Platform

| Product | What it does |
|---|---|
| **Token Factory** | Chat, image, and video inference APIs, compatible with the OpenAI and Anthropic formats |
| **GPU Supernode** | Dedicated supernode compute for production workloads (early access) |

## Open source

- **SDKs and examples** for building on the wylon API
- **Developer tools** for inference workflows
- **Ecosystem plugins**, such as ComfyUI custom nodes

Repositories will appear here as they're published.
